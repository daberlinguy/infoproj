# Parkour Game

[![Documentation](https://img.shields.io/badge/Documentation-daberlinguy.github.io%2Finfoproj-blue?logo=readme&logoColor=white&style=for-the-badge)](https://daberlinguy.github.io/infoproj/)

A 2D platformer game built with Python and Pygame featuring smooth character movement, customizable characters, and easy level creation.

## 📚 Documentation

Complete documentation is available at: **[https://daberlinguy.github.io/infoproj/](https://daberlinguy.github.io/infoproj/)**

## ✨ Features

- 🎮 Smooth character physics and movement
- 🎨 Customizable characters and sprites
- 🏗️ Level editor for creating custom levels
- 🔧 Extensible architecture for adding new features
- 📦 Built with Python and Pygame

## 🚀 Quick Start

See the [Installation Guide](https://daberlinguy.github.io/infoproj/getting-started/installation/) for detailed setup instructions.

### Basic Usage

```bash
# Run the game
python src/code/main.py

# Run the editor
python editor/main.py
```

## 📁 Project Structure

```
infoproj/
├── src/              # Main game source code
│   ├── code/         # Game logic and screens
│   └── resources/    # Assets and textures
├── editor/           # Level editor
├── levels/           # Game levels
├── docs/             # Documentation (Astro/Starlight)
├── packaging/        # Build scripts
└── data/             # Game data files
```
