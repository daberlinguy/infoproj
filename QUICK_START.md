# Quick Start Guide

## Level Editor
Double-click `run_editor.bat` to launch the level editor!

### Controls
- **Draw**: Left-click and drag
- **Erase**: Middle-click or Shift+Left-click
- **Save**: Ctrl+S
- **Load**: Ctrl+O
- **New**: Ctrl+N
- **Toggle Grid**: G

### Steps
1. Select a block type (bottom panel)
2. Choose a color
3. Draw your level
4. Save with Ctrl+S

## Playing Custom Levels
1. Run `main.py`
2. Click "Levels"
3. Select "world1"
4. Click a level number
5. Reach the gold finish block (F) to complete!

## Block Types
- **Normal** (Gray) - Standard platform
- **Death** (Red) - Respawn at checkpoint
- **Spawn** (Green) - Start position
- **Checkpoint** (Yellow) - Save point
- **Slippery** (Blue) - Ice physics
- **Finish** (Gold) - Level goal

Enjoy creating levels!
